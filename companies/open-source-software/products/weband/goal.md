## 之后（P1，需要外设到位）
硬件对标参考设备 **V1 圆屏**（2026-11-10 决定），外设以 V1 为准，详见 `AGENTS.md` 第一节。

- M3 音频链：模拟 MEMS 麦 → 片内 audcodec ADC。**硬件链路已实测通过（2026-11-10）**：3037 模拟麦接 `VCC`→J1-5（MIC_BIAS）、`OUT`→J1-4（MIC_ADC，板上已有 2.2 µF 隔直）、`GND`→J1-1。用 SDK `audprc` 例程录音，出声时比安静时高 10–28 dB（−51 → −23 dBFS）。导出 WAV 试听正常（音调、语速无异常，2026-11-11 用户确认）。MIC_BIAS 电压本身没实测（没有万用表），但麦能正常拾音。剩下的是固件：VAD + Opus 编码录音。
  - **M3 固件已完成（2026-11-13）**：已合入 Weband `main` 并推送（`97ec141`）。结案条件：WebRTC VAD 门控 + Opus（SILK 16 kHz 24 kbit/s）分段录到 fs_region；已用超过 2/3 自动裁剪（先删已传到手机的）；5 分钟落盘；按原版 App 1.3.1 协议经 BLE 传给手机，大小与 CRC 一致、可解码、丢块重传、断线续传。以上均已真机实测通过。
  - 已知遗留（用户决定不阻塞 M3，单独立项）：桌面敲击等短促声响仍会开段（敲击 1 分钟开 4 段）。
- **Weband 不要屏幕**（2026-11-13 用户决定）：V1 的圆形反射屏（LPM012M134B）不做，不再采购屏和转接。
- V1 器件（开源硬件页，2026-11-13）：主控 SF32LB525UC6；录音存 128 MB SD NAND（MKDV1GCL-ABF）；程序 16 MB SPI NOR（PY25Q128HA）；电池 502525。
- M4 电源（不含显示）：电源键语义 + 片内充电。**充电在 Nano 上做不了**（SF32LB52JUD6 不带充电），要验充电需另购锂电版芯片的板子（如 SF32LB52-DevKit-LCD）+ 锂电池；不再买 LGS4056。
- IMU（LSM6DS3TR-C）：V1 原理图有，但 V1 固件反汇编确认不访问（2026-11-10），不对标、不排期。
